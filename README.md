# Amazon Clone

**Project:** Amazon-clone-main

**Short Description:** A Flutter-based e-commerce application (Amazon-like) with a Node.js + Express backend and MongoDB for persistence. This repository contains the Flutter client, platform folders (Android/iOS/web/desktop), and a simple REST API server in the `server/` folder.

**Tech Stack:**
- Flutter & Dart (mobile, web, desktop)
- Node.js + Express (backend API)
- MongoDB (database)

**Key Dependencies (server):** `express`, `mongoose`, `bcryptjs`, `jsonwebtoken` (see `server/package.json`).

**Overview**
- **Purpose:** This project is an Amazon-like e-commerce app implemented in Flutter, backed by a Node.js REST API. It is intended as a learning / demo project and a base for further extension.
- **Platforms:** Android, iOS, Web, Windows, macOS, Linux (platform-specific support depends on your local Flutter setup).

**Features**
- Product listing and details
- User authentication (signup / login)
- Shopping cart and order creation
- Ratings and reviews
- Admin routes for product management (in server)

**Prerequisites**
- **Flutter:** Install the Flutter SDK. Follow the official guide: https://flutter.dev/docs/get-started/install
- **Dart:** Bundled with Flutter.
- **Node.js & npm:** Install Node.js (recommended LTS). https://nodejs.org/
- **MongoDB:** A running MongoDB instance (local or cloud). https://www.mongodb.com/
- **PowerShell (Windows):** Commands below assume PowerShell; adjust for other shells if needed.

**Quick Start**

- Backend (server)

  1. Open a terminal and navigate to the `server/` directory:

```powershell
cd "c:\Users\jaiad\OneDrive\Desktop\Amazon Clone\amazon-clone-main\server"
```

  2. Install dependencies:

```powershell
npm install
```

  3. Create an environment file `.env` (example keys listed below), then start the server in dev mode:

```powershell
npm run dev
```

  4. Production start:

```powershell
npm start
```

- Flutter App (client)

  1. From the repository root, get Flutter packages:

```powershell
cd "c:\Users\jaiad\OneDrive\Desktop\Amazon Clone\amazon-clone-main"
flutter pub get
```

  2. Run the app (example: run on a connected device or emulator):

```powershell
flutter run
```

  3. To run on web (Chrome):

```powershell
flutter run -d chrome
```

**Project Structure (high level)**
- `lib/` — Flutter app source code

  - `providers/` — State providers
  - `constants/` — Global constants and utilities
- `server/` — Node.js backend

- `android/`, `ios/`, `web/`, `windows/`, `linux/`, `macos/` — Platform folders generated by Flutter

**Environment / Configuration**
- Backend (`server/`): create a `.env` file (in `server/`) with at least:
  - `MONGO_URI` — MongoDB connection string
  - `JWT_SECRET` — Secret for signing JWT tokens
  - Any other keys your server requires (check `server/index.js` or other server files).

- Client (Flutter): the app may require updating a base API URL or other keys. Check `lib/constants/global_variables.dart` or `lib/constants/utils.dart` for places to set the backend URL.

**Development Tips**
- Use `nodemon` for automatic backend reloads (`npm run dev`).
- Use Android Emulator or iOS Simulator for mobile testing, and `flutter run -d chrome` for quick web testing.
- Keep the server running while testing API-dependent flows in the Flutter app.
- If you use a remote MongoDB instance (like MongoDB Atlas), ensure network access and IP whitelist are configured.
